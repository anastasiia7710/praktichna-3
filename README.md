n = int(input("Введіть n="))

#### Завдання 4
Розв’язати систему 2-х лінійних рівнянь з двома невідомими методом Крамера.
```javascript
#a1*x + b1*y = c1
#a2*x + b2*y = c2
a1 = float(input("Введіть a1: "))
b1 = float(input("Введіть b1: "))
c1 = float(input("Введіть c1: "))
a2 = float(input("Введіть a2: "))
b2 = float(input("Введіть b2: "))
c2 = float(input("Введіть c2: "))
delta = a1 * b2 - a2 * b1
if delta == 0:
    print("Визначник системи дорівнює 0.")
    print("Система або не має розв'язків, або має безліч розв'язків.")
else:
    delta_x = c1 * b2 - c2 * b1
    delta_y = a1 * c2 - a2 * c1
    x = delta_x / delta
    y = delta_y / delta
    print(f"Результат: {x}, {y}")
```
#### Завдання 5
Скласти програму, яка обчислює площу фігури за її номером
```javascript
from math import *
print("Обчислення площі фігури")
print("1 - площа прямокутника")
print("2 - площа трикутника")
print("3 - площа трапеції")
print("4 - площа круга")
n = int(input("Введіть номер фігури n= "))
if n == 1:
    # Площа прямокутника: S = a * b
    a = float(input("Введіть сторону a: "))
    b = float(input("Введіть сторону b: "))
    S = a * b
    print(f"Площа прямокутника: S = {S}")
elif n == 2:
    # Площа трикутника: S = (a * h) / 2
    a = float(input("Введіть основу a: "))
    h = float(input("Введіть висоту h: "))
    S = (a * h) / 2
    print(f"Площа трикутника: S = {S}")
elif n == 3:
    # Площа трапеції: S = ((a + b) / 2) * h
    a = float(input("Введіть основу a: "))
    b = float(input("Введіть основу b: "))
    h = float(input("Введіть висоту h: "))
    S = ((a + b) / 2) * h
    print(f"Площа трапеції: S = {S}")
elif n == 4:
    # Площа круга: S = π * R^2
    R = float(input("Введіть радіус R: "))
    S = math.pi * (R ** 2)
    print(f"Площа круга: S = {S:.2f}")
else:
    print("Помилка: фігури з таким номером немає (введіть 1, 2, 3 або 4).")
```
#### Завдання 6
Скласти програму обчислення значення функції:
```javascript
from math import *
def calculate_function(x):
    if -2 <= x <= 2:
        return x**2
    else:
        return 4 * exp(x)
x = float(input("Введіть значення x="))
result = calculate_function(x)
print(f"Для x={x} значення функйії f(x) =: {result:.4f}")
```
#### Завдання 7

    if x<0:
        return tan(abs(x))
    elif 0 <= x < 5:
        return x**3
